Finished photos folder and Immich

Deliver copies each shoot’s finished JPEGs into its own folder here, such as MyPhoto\2026-11-06_夜景, after you’ve checked them. Files already there are never replaced or removed.

With Immich set up, Card Intake asks the library that watches the finished photos folder to rescan after each delivery. Use an admin API key with library.read and library.update permissions. Clear the URL and save to disconnect Immich.

Camera and shutter count

Read from every photo's EXIF with ExifTool (Sony keeps the count in encrypted maker notes). The history is saved in the NAS photo folder, in .card-intake/shutter.sqlite, so every computer running Card Intake shows the same graph. Rated life appears only for models with a published rating.

Capture times

Photos use EXIF DateTimeOriginal; Sony clips use the CreationDate in their XML sidecar. File dates are a last resort, because copying a card can change them.

Card health

CFexpress cards are NVMe drives with their own health log and serial number, whichever camera formatted them: a Nikon Z 9’s Type B card reads like a Sony card. When the reader shows the card as an NVMe drive (Thunderbolt or USB4, e.g. an MRW-G3 on a USB4 port), Windows reads both on insertion without admin rights. In a USB reader with a JMicron JMS583 bridge (e.g. a CHIPFANCIER CFexpress Type B reader), the app reads them through the bridge once Windows gives admin rights. Behind other USB bridges it takes smartctl and admin rights. macOS can’t read cards in USB readers. SD cards keep no health log.
