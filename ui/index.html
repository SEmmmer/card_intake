Camera, serial number, firmware

Read from the newest photo's EXIF. The shutter count sits in Sony's encrypted maker notes, so it needs ExifTool.

Capture times

Photos use EXIF DateTimeOriginal; Sony clips use the CreationDate in their XML sidecar. File dates are a last resort, because copying a card can change them.

Card health

Read from the CFexpress card's own NVMe health log with smartctl. On Windows this works through most USB readers and asks for admin rights. macOS can't pass the commands through a USB reader. SD cards keep no health log.
